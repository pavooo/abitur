JSON-Format für das eigene KI-Werkzeug

Dasselbe Format wie beim Admin-Import (schema/klausur.schema.json), nur ohne das Feld id und ohne Koordinaten – Teilaufgaben haben nur eine Seitenzahl, keine Bereiche. Die übrigen Metadaten (Fach, Jahr, Kursart, Termin, Variante, Titel, Hilfsmittel) sind optional: Schritt 1 behält in jedem Fall Vorrang, Abweichungen werden nur zur Kontrolle angezeigt.

aufgabenArrayPflicht, mindestens ein Eintrag
fach, jahr, kursart, termin, variante, titel, hilfsmittel–Optional, nur zum Abgleich mit Schritt 1
